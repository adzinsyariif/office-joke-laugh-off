## The joke

> My boss said dress for the job you want, so I showed up in pajamas wearing an Out of Office sign.

## Run

`main.py` writes the joke to `/output/entry.txt` (UTF-8, no trailing newline).

```sh
python3 main.py
cat /output/entry.txt
```
